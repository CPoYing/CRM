# 專案追蹤工具（Streamlit）

支援主任務 / 子任務層級、狀態追蹤、進度統計，以及時程甘特圖的小工具。

## 功能

- **任務清單**：可直接編輯（新增 / 刪除 / 修改），WBS、層級、任務名稱、負責人、狀態、優先順序、進度、日期、備註
- **自動存檔**：每次修改都會寫到 `data/tasks.json`，關掉瀏覽器或重新整理都不會不見
- **自動統計**：主任務數、已完成 / 進行中 / 延遲 / 未開始、完成率、整體進度、已逾期
- **時程甘特圖**：Plotly Timeline，依狀態上色，標示今天的位置；子任務沒填日期時可沿用主任務日期
- **一鍵整理**：由子任務平均值重算主任務進度、把逾期任務標記為延遲
- **匯出**：格式化 Excel（日期為真正的日期格式，含下拉驗證）或 CSV（UTF-8 with BOM）
- **上傳**：可上傳既有 Excel / CSV 覆蓋資料，欄位缺漏或值不合法會自動修正

## 快速啟動

```bash
cd project_tracker_app
pip install -r requirements.txt
streamlit run app.py
```

瀏覽器會自動開啟 `http://localhost:8501`

## 部署到 Streamlit Cloud

1. 到 [share.streamlit.io](https://share.streamlit.io) 連線這個 repo
2. Main file path 填 `project_tracker_app/app.py`
3. 部署完成後即可用公開網址使用

> ⚠️ Streamlit Cloud 的檔案系統是暫時的，`data/tasks.json` 在服務重啟後會消失。
> 雲端版請把它當唯讀展示用，重要資料請用「匯出」下載備份，或改接資料庫 / Google Sheets。

## 資料說明

- 預設已內建「合約 / 訂單 / 出貨 / 點銅…」等模組資料
- 第一次啟動會用內建預設資料；之後一律讀 `data/tasks.json`
- `data/` 不會進版控（已列入 `.gitignore`），所以每台機器的資料是各自獨立的
- 側邊欄「還原預設資料」可隨時重置

## 欄位規則

| 欄位 | 說明 |
| --- | --- |
| WBS編號 | 主任務用 `1`、`2`…，子任務用 `1.1`、`1.2`…；排序是自然排序，`10` 會排在 `9` 後面 |
| 層級 | 主任務 / 子任務 |
| 狀態 | 未開始 / 進行中 / 已完成 / 暫停 / 延遲 |
| 優先順序 | 高 / 中 / 低 |
| 進度(%) | 0–100 |
| 開始 / 截止日期 | 真正的日期欄位，可留空 |

「已逾期」的定義是：截止日期已過，且狀態不是「已完成」。
